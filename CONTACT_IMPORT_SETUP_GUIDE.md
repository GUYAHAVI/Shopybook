# Contact Import System - Setup Guide

This guide will help you set up the bulk contact import feature for SMS campaigns in Shopybook.

## Features

The contact import system allows users to:
- ✅ Import contacts from **Google Contacts** (OAuth)
- ✅ Upload **CSV/Excel** files (from computer or exported from phone)
- ✅ Upload **VCF (vCard)** files (exported directly from iPhone/Android)
- ✅ Organize contacts into groups (Customers, Staff, Suppliers, Custom)
- ✅ Sync existing customers and employees from the database
- ✅ Send bulk SMS to entire contact groups

## Installation Steps

### 1. Install Dependencies

Run the following command to install the required packages:

```bash
composer update
```

This will install:
- `google/apiclient` - For Google Contacts API integration
- `maatwebsite/excel` - For CSV/Excel import (already installed)

### 2. Run Database Migrations

Create the necessary database tables:

```bash
php artisan migrate
```

This creates two new tables:
- `contact_groups` - Stores contact group information
- `imported_contacts` - Stores imported contacts

### 3. Set Up Google OAuth (Optional but Recommended)

To enable Google Contacts import, you need to set up Google OAuth credentials:

#### Step 1: Create Google Cloud Project

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project or select an existing one
3. Enable the **People API** (Google Contacts API)
   - Go to "APIs & Services" > "Library"
   - Search for "People API"
   - Click "Enable"

#### Step 2: Create OAuth Credentials

1. Go to "APIs & Services" > "Credentials"
2. Click "Create Credentials" > "OAuth client ID"
3. Select "Web application"
4. Add authorized redirect URIs:
   ```
   http://localhost/contacts/google/callback
   https://yourdomain.com/contacts/google/callback
   ```
5. Copy the **Client ID** and **Client Secret**

#### Step 3: Add to .env File

Add the following to your `.env` file:

```env
# Google OAuth for Contact Import
GOOGLE_CLIENT_ID=your_client_id_here
GOOGLE_CLIENT_SECRET=your_client_secret_here
GOOGLE_REDIRECT_URI=${APP_URL}/contacts/google/callback
```

### 4. Configure SMS Service (Already Set Up)

The contact import integrates with your existing HostPinnacle SMS service. No additional configuration needed if you've already set up:

```env
HOSTPINNACLE_USERNAME=your_username
HOSTPINNACLE_API_KEY=your_api_key
HOSTPINNACLE_SENDER_ID=SHOPYBOOK
```

## Usage Guide

### For Users

#### Creating a Contact Group

1. Navigate to **Contacts** (accessible from the Marketing section)
2. Click "New Contact Group"
3. Enter:
   - **Group Name**: e.g., "VIP Customers", "Sales Team"
   - **Type**: Customers, Staff, Suppliers, or Custom
   - **Description**: Optional description
4. Click "Create Group"

#### Importing Contacts

##### Option 1: Import from Google Contacts

1. Go to your contact group
2. Click "Import Contacts"
3. Click "Import from Google"
4. Sign in with your Google account
5. Grant access to read contacts
6. Contacts will be automatically imported

##### Option 2: Upload CSV/Excel File

1. Click "Upload CSV/Excel"
2. Select your file (or download the template first)
3. File should include columns:
   - `name` (required)
   - `phone` (required)
   - `email`
   - `company`
   - `position`
   - `address`
   - `notes`

##### Option 3: Upload VCF File from Phone

**iPhone:**
1. Go to iCloud.com
2. Open Contacts
3. Select contacts to export
4. Click gear icon > "Export vCard"
5. Upload the .vcf file to Shopybook

**Android:**
1. Open Contacts app
2. Menu (⋮) > Settings > Export
3. Export to .vcf file
4. Upload to Shopybook

##### Option 4: Sync Existing Data

In any contact group, you can:
- Click "Sync Existing Customers" - imports from your customer database
- Click "Sync Existing Employees" - imports from your employee database

### Sending Bulk SMS

1. Go to **Marketing** > **Bulk SMS**
2. Select recipient type:
   - **Individual Customers**: Select specific customers
   - **Contact Groups**: Select entire groups
3. Write your message (or use a template)
4. Click "Send SMS"
5. Confirm the number of recipients

## File Format Examples

### CSV Format

```csv
name,phone,email,company,position,address,notes
John Doe,254712345678,john@example.com,Acme Corp,Manager,"123 Main St",VIP customer
Jane Smith,0722345678,jane@example.com,Tech Ltd,Developer,"",Regular customer
```

### VCF Format

VCF files are automatically generated by phone contacts apps. They look like:

```
BEGIN:VCARD
VERSION:3.0
FN:John Doe
TEL:+254712345678
EMAIL:john@example.com
ORG:Acme Corp
TITLE:Manager
END:VCARD
```

## Troubleshooting

### Google Import Not Working

1. **Check credentials**: Ensure `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` are set
2. **Verify redirect URI**: Must match exactly in Google Console and `.env`
3. **Enable People API**: Check that People API is enabled in Google Cloud Console
4. **Clear cache**: Run `php artisan config:clear`

### CSV Import Failing

1. **Check file format**: Ensure file is proper CSV with headers
2. **Verify columns**: Required columns are `name` and `phone`
3. **File size**: Maximum 10MB
4. **Encoding**: Use UTF-8 encoding

### VCF Import Issues

1. **File format**: Ensure file is valid vCard format
2. **Export correctly**: Use proper export from phone contacts
3. **File size**: Keep under 10MB

### SMS Not Sending to Groups

1. **Check SMS configuration**: Verify HostPinnacle settings
2. **Verify group has contacts**: Check contact group has imported contacts
3. **Phone number format**: Ensure phone numbers are valid
4. **Check logs**: Look at Laravel logs for errors

## API Limits

### Google Contacts API
- **Rate limit**: 600 requests per minute per user
- **Quota**: 15,000 requests per day (default)
- For high-volume imports, request quota increase from Google

### File Upload Limits
- **CSV/Excel**: 10MB maximum
- **VCF**: 10MB maximum
- Modify in `ContactImportController.php` if needed

## Advanced Configuration

### Changing Phone Number Format

Edit `app/Models/ImportedContact.php` - `getFormattedPhoneAttribute()` method:

```php
// Default formats Kenyan numbers (254)
// Modify for your country code
if (substr($phone, 0, 1) === '0') {
    $phone = '254' . substr($phone, 1); // Change 254 to your country code
}
```

### Custom Contact Fields

To add custom fields to contacts:

1. Create migration to add column to `imported_contacts` table
2. Update `ImportedContact` model's `$fillable` array
3. Update import services to handle new field
4. Update view to display new field
